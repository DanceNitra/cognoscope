Cognoscope — Runtime Bias Detection Engine

Cognoscope Dashboard

Real-time detection of cognitive biases in AI agent behaviour. Monitors tool selection, reasoning traces, and output patterns to identify anchoring, confirmation bias, escalation of commitment, overconfidence, loss aversion, framing effects, drift, and feedback delay. Each detected bias triggers a targeted context injection. The system learns which interventions work via Thompson sampling.
